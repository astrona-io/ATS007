# Admission Controllers Integration Capstone

Welcome to the Section 030 Capstone Challenge. In this lab, you will connect every concept from this section: install a scoped policy, confirm Kyverno's self-managing webhook reacted to it, roll enforcement out safely through Audit mode first, and only then flip to Enforce and prove the block.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS007.git -c sections/section-030/capstone/labs/lab-01
```
