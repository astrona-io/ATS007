# Mutate & Generate Rules Sandbox

Welcome to the Module 3 targeted practice sandbox. In this lab, you will write a mutate rule that labels Pods and a generate rule that auto-creates a default-deny NetworkPolicy in every new namespace.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS007.git -c sections/section-010/module-03/labs/lab-01
```
