# Kyverno Policy & Rule Anatomy Sandbox

Welcome to the Module 1 targeted practice sandbox. In this lab, you will author a `ClusterPolicy` from scratch, correctly scope it with `match`/`exclude`, and prove it enforces a required label on Pods.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS007.git -c sections/section-010/module-01/labs/lab-01
```
