# YAML Manifests Integration Capstone

Welcome to the Section 020 Capstone Challenge. In this integration lab, you will author a namespaced policy from scratch, pull live cluster state with `context[].apiCall`, resolve a JMESPath variable, and surface it in a custom rejection message — connecting everything from both modules in this section.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS007.git -c sections/section-020/capstone/labs/lab-01
```
