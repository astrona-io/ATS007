# Section 040 Capstone: OCI Image Trust Integration

Welcome to the Section 040 Capstone Challenge. This lab combines digest resolution and Kyverno image-verification enforcement into one integrated scenario.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS007.git -c sections/section-040/capstone/labs/lab-01
```
