# OCI Image Fundamentals Sandbox

Welcome to the Module 1 targeted practice sandbox. In this lab, you will practice resolving the real digest behind a mutable image tag and pinning a Deployment to that digest.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS007.git -c sections/section-040/module-01/labs/lab-01
```
